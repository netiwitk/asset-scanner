# สแกนทรัพย์สิน (asset-scanner)

แอปมือถือ Flutter สำหรับคนหน้างาน ใช้คู่กับระบบหลังบ้าน [asset-laravel](https://github.com/netiwitk/asset-laravel)

- สแกนคิวอาร์โค้ดบนป้ายครุภัณฑ์ แล้วเห็นสถานะ หน่วยงาน มูลค่าตามบัญชี และผู้ยืมทันที
- เจ้าหน้าที่พัสดุกดส่งมอบหรือรับคืนได้จากหน้างาน และเลือกได้ว่าของคืนมาในสภาพใช้งานได้หรือชำรุด
- พนักงานดูได้เฉพาะของหน่วยงานตัวเอง ถ้าสแกนของหน่วยงานอื่นจะขึ้นว่า "ไม่พบ"

## ทำงานกับระบบหลังบ้านอย่างไร

แอปเรียก API ของ asset-laravel (`/api/assets/{tag}`) ด้วย token ที่ได้ตอน login
ระบบหลังบ้านเป็นคนตัดสินว่าแต่ละคนกดปุ่มไหนได้ แล้วส่งรายชื่อปุ่มมาให้แอปวาดเท่านั้น
กฎชุดเดียวกับหน้าเว็บ แอปจึงไม่มีทางแสดงปุ่มที่หลังบ้านจะปฏิเสธ

ป้าย QR ใส่ได้ทั้งรหัสเปล่า (`AV-67-0037`) หรือลิงก์มาที่แอป (`https://.../#/a/AV-67-0037`)
แบบลิงก์ใช้กล้องปกติของมือถือส่องได้เลย ไม่ต้องเปิดแอปก่อน

## รัน

```bash
flutter pub get
flutter test

# เว็บ (ทดสอบในเครื่อง ชี้ไปที่ asset-laravel ที่รันอยู่ และเปิดปุ่ม demo)
flutter run -d chrome --dart-define=API_URL=http://127.0.0.1:8000 --dart-define=DEMO=true

# Android
flutter build apk --dart-define=API_URL=https://asset-laravel.onrender.com
```

ถ้าไม่ใส่ `API_URL` แอปจะชี้ไปที่ demo บน Render ซึ่งเป็นเครื่องฟรี ถ้าไม่มีคนใช้สักพักจะหลับ
ครั้งแรกจึงอาจรอราว 1 นาที
